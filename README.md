## 🚀 대표 프로젝트

### KTL 정도검사 현장 데이터 관리 시스템 · 진행 중

현장에서 수집한 사진과 로거 데이터를 관리하고, 판독·검토한 결과를 검사 문서에 활용할 수 있도록 지원하는 프로젝트입니다.

- **담당 역할:** 현장 서버 백엔드 개발. FastAPI 기반 모바일·관리자 API 분리, 검사 접수 건 생성·조회·검색, 검사 분류별 입력 검증 및 데이터베이스 구성.
- **사용 기술:** Python, FastAPI, Pydantic, SQLAlchemy, SQLite, Alembic
- **해결한 문제:** 관리자 API를 로컬에서만 접근하도록 분리하고 외부 접근을 차단했습니다. 검사 분류별로 허용되는 선택 항목과 값을 검증해 잘못된 데이터 입력을 방지했습니다.
- **저장소:** [ktl-field-server](https://github.com/Destiny-star03/ktl-field-server)
